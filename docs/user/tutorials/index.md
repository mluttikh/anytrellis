# Tutorials

Lessons to follow in order, in a notebook. Each takes about ten minutes, and each is also
a notebook in [`examples/`](https://github.com/mluttikh/anytrellis/tree/main/examples) you
can run.

1. [Your first trellis plot](first-plot.md): a panel per group, looking around in the plot,
   colours, a second layer, and a page to share.
2. [Facets and scales](facets-and-scales.md): grids, empty cells, free scales, log scales
   and the order of panels.
3. [Select data and use it in Python](select.md): brushing, legend clicks, following
   things across panels, and the selected rows in Python.

For a task rather than a lesson, see the [how-to guides](../how-to/index.md).
